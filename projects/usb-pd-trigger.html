Overview

Designed a compact USB-C Power Delivery trigger PCB in KiCad that negotiates selectable PD voltages (5V, 9V, 12V, 15V, and 20V) using the HUSB238 controller. The board includes USB-C input protection with ESD, TVS, and a resettable polyfuse, a PMOS-controlled output power path, configurable voltage selection via jumpers, status LEDs, and a screw-terminal output. Completed from schematic capture through PCB layout with clean ERC and DRC verification.

Functional Overview

USB-C Input Stage

  • USB-C receptacle with CC1/CC2 sense lines
  • ESD protection array and TVS clamping on VBUS
  • Resettable polyfuse for input overcurrent protection

PD Negotiation

  • HUSB238 PD sink controller handling the USB-C PD handshake
  • Selectable output voltage (5V/9V/12V/15V/20V) via jumper header
  • Voltage-set resistor network setting the VSET/ISET thresholds

Output Power Path

  • PMOS-controlled switch gating VBus to Vout once negotiation completes
  • Bulk output capacitance for ripple filtering
  • Screw-terminal output for easy load connection

Status Indication

  • Power LED indicating VBus presence
  • Output LED indicating an active, negotiated output

PCB Design Highlights

  • Compact two-layer layout completed from schematic capture through routing
  • Clean ERC and DRC verification prior to fabrication
  • 3D PCB render for mechanical/enclosure fit checks
