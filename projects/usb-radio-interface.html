This was a freelance engagement for a commercial telecom client. Client and end-use details are confidential — the summary below covers the engineering scope only.

Overview

Designed a fully-isolated USB-to-radio interface board for a commercial telecom client, combining ADuM3160 USB isolation, a CM119B audio codec, and an FT231X UART bridge with dual-OS PTT/COR control — Linux HID GPIO on one side and Windows FTDI modem lines on the other — for drop-in compatibility with Asterisk chan_usbradio.

Key Features

  • ADuM3160-based USB isolation barrier
  • CM119B audio codec for radio audio I/O
  • FT231X UART bridge for control and data
  • Dual-OS PTT/COR control: Linux HID GPIO and Windows FTDI modem lines
  • Drop-in compatibility with Asterisk chan_usbradio

Manufacturing & Delivery

  • Manufacturing-ready KiCad package: schematic, PCB, Gerbers, BOM/CPL, and panel drilling drawings
  • Delivered for JLCPCB fabrication
  • Resolved isolation-barrier creepage/clearance and thermal/signal-integrity considerations
  • Verified alternate/second-source components (CM108 family, genuine-vs-counterfeit FTDI) for supply resilience
