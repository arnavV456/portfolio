ESP32 Brushed Quadcopter Flight Controller

A custom-designed flight controller for a 1S brushed quadcopter, built around the ESP32-WROOM-32 with onboard IMU sensing and direct MOSFET-driven motor control - currently in hardware bring-up.

ESP32-WROOM-32 Flight controller MCU
MPU6500 6-axis IMU
4× AO3400A Brushed motor drive

Overview

Designed a custom flight controller board for a 1S brushed quadcopter around the ESP32-WROOM-32, combining onboard MPU6500 IMU sensing with four AO3400A low-side MOSFETs for direct PWM motor drive. The board integrates power regulation, USB-C for programming, and onboard status indicators onto a single compact two-layer PCB.

The board is currently in hardware bring-up - validating power delivery, IMU communication, and motor driver switching ahead of flight firmware integration.

Key Features

  • ESP32-WROOM-32 as the flight controller core
  • MPU6500 6-axis IMU for attitude sensing
  • 4× AO3400A low-side MOSFETs for direct brushed-motor PWM drive, with gate and pull-down resistor networks
  • USB-C connector for programming and power
  • 1S LiPo input with onboard power switch and bulk/decoupling capacitors
  • Reset and boot/user tactile buttons

Design Process

  • Validated the core architecture - ESP32 firmware, IMU communication, and PWM motor control - on a breadboard/perfboard proof-of-concept before committing to a custom PCB
  • Laid out a compact two-layer PCB in KiCad, integrating the IMU, motor drivers, power regulation, and USB-C interface onto a single board
