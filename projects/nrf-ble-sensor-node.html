nRF52840 BLE Sensor Node

A compact 30×35mm Bluetooth Low Energy sensor node built around the nRF52840, with USB-C Li-ion charging and power-path management, onboard microSD data logging, and a hand-routed 50Ω PCB antenna feed - designed from the datasheet up and taken through clean ERC/DRC.

nRF52840 BLE 5.x SoC
MCP73871 USB-C charge + power-path
30×35mm Four-layer PCB

Overview

Designed a 30×35mm BLE sensor node around the nRF52840 QFN, built for battery-powered field logging: USB-C in, Li-ion charging and power-path management on the way through, a regulated 3.3V rail, onboard microSD storage, and a matched PCB antenna feed. The board was built up pin-by-pin from the MCP73871 and TPS7A20 datasheets rather than copied from a reference layout, then routed, silkscreened, and verified through clean ERC and DRC.

Functional Overview

Power System

  • USB-C VBUS feeds the MCP73871 linear charge management IC, which manages Li-ion charging and system power-path simultaneously
  • System load is always sourced from the MCP73871's regulated SYS output, never directly from the battery, so brownout during heavy charge current is avoided
  • Charge current set via PROG1 (~500mA) and termination current via PROG3, with the safety timer left enabled
  • CE tied to VBUS so the charger is only enabled while USB power is present; PG/STAT1/STAT2 status outputs drive onboard LEDs
  • JST battery connector with input, output, and battery bulk capacitance placed per the datasheet's typical application circuit

3.3V Regulation

  • TPS7A20 LDO regulates the SYS rail down to a clean 3.3V for the MCU and sensors
  • Selected for its 6.5µA quiescent current and 1.6–6.0V input range, both well suited to a battery-backed, low-duty-cycle sensor node
  • Minimal footprint: single 1µF input and output ceramic capacitor, per datasheet

MCU & RF

  • nRF52840 QFN as the BLE radio and application core
  • Hand-routed 50Ω controlled-impedance feed from the chip to the antenna, with trace geometry calculated for the board's stackup
  • Careful escape routing off the QFN's fine-pitch pads, including matched RF and ground return routing back through stitched vias to the L2 ground pour

Data Logging

  • Onboard microSD card slot for local sensor data logging independent of the BLE link

User Interface & Debug

  • 10-pin SWD debug header for programming and in-circuit debugging
  • User and reset tactile buttons
  • RGB status LED

PCB Design Highlights

  • Compact four-layer, 30×35mm layout with a dense mixed-signal component placement (charger, LDO, MCU, RF, and microSD on one board)
  • Controlled-impedance 50Ω antenna trace tuned to the four-layer copper stackup
  • Solid L2 ground plane stitched to the top-layer ground pour with return-path vias placed for RF and digital return continuity
  • Custom silkscreen branding and labeled interfaces (USB, SWD, µSD, BAT, buttons, LEDs) for a clean, product-like finish
  • Clean ERC and DRC verification prior to fabrication
